Proyecto de navegacion en Android desarrollado por el estudiante Nikolai Suarez en el curso de programacion de moviles. Este proyecto corresponde a la implementacion inicial sin asistencia de inteligencia artificial. En este trabajo se construyo la estructura base de navegacion utilizando Jetpack Compose, definiendo las pantallas principales como inicio, detalle, lista y perfil, asi como el enrutamiento basico entre ellas mediante componentes de navegacion y contenedores visuales estandar.
